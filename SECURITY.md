# Безопасность

Виджет работает в браузере OBS и использует OAuth PKCE. Ему не нужен Client Secret или локальное приложение.

## Не публикуй

- `refresh_token` и `access_token`;
- JSON, который выводит кнопка «Показать подключение для переноса»;
- сетевые заголовки `Authorization`;
- скриншоты панели разработчика с секретными данными;
- содержимое browser storage или конфигурации OBS с секретами.

Публичный `Client ID` не является секретом, но права API зависят от аккаунта и настроек приложения.

## Если токен утёк

1. Прекрати использование скомпрометированного подключения.
2. В настройках аккаунта Spotify отзови доступ приложению.
3. Повтори авторизацию и заново импортируй подключение в OBS.
4. Если подозреваешь компрометацию приложения разработчика, проверь его настройки и разрешённых пользователей.

## Политика зависимостей

Продакшн-виджет — статическая страница без NPM-зависимостей и сторонних JavaScript-CDN. Дополнительный JS на том же домене может получить доступ к refresh token из `localStorage`; не размещай рядом недоверенные страницы.

О проблемах, связанных с раскрытием секретов, лучше сообщать автору репозитория приватно, а не через публичный issue с токенами.
