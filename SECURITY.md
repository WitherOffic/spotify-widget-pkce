# Безопасность Wither Spotify Widget

Проект использует два разных типа секретов:

- **Spotify refresh token:** хранится в Cloudflare D1 только в зашифрованном виде (AES-256-GCM, ключ `TOKEN_ENC_KEY` находится в Cloudflare Secrets). В OBS никогда не передаётся.
- **Ключ для OBS:** случайный непрозрачный идентификатор, позволяющий **только читать текущую музыку**. Содержится в URL браузерного источника OBS. Обладатель ссылки сможет наблюдать воспроизведение, но не управлять Spotify.

Другие секреты:
- `PAIRING_KEY` — доступ к запуску новой авторизации, хранится только в Cloudflare Secrets и вводится при подключении на главной странице.
- **Owner key** — отдельный ключ управления ссылкой (перевыпуск/отключение). Хранится в localStorage браузера главной панели, не в OBS.
- `TOKEN_ENC_KEY` — 32 криптографически случайных байта в Base64. При потере/замене придётся авторизоваться заново.

## Не публикуй

- Полные URL OBS и любые содержащиеся в них ключи просмотра;
- `PAIRING_KEY`, `TOKEN_ENC_KEY`, owner key;
- Spotify access/refresh token, OAuth state, заголовки `Authorization`;
- Содержимое D1, localStorage и необработанные сетевые логи с секретами.

## Если ссылка OBS утекла

Открой главную панель Wither Spotify Widget и нажми **Перевыпустить ссылку**. Старая перестанет работать. Если утекли более серьёзные секреты, отзови доступ приложения в Spotify и замени секреты Worker.

Вызовы Cloudflare Worker защищены случайными ключами, проверкой допустимого Origin и изоляцией Spotify-токенов на сервере. CORS сам по себе не заменяет авторизацию — поэтому для API используются отдельные криптографически случайные ключи.

## Известные ограничения

- Секрет просмотра виден владельцу полного URL браузерного источника OBS. Не публикуй конфигурацию OBS без удаления этого URL.
- Серверные ошибки и время ответа Spotify могут замедлять обновления. Интервал 3 секунды не означает мгновенную реакцию.
- Cloudflare Worker с D1 — облачная зависимость; применяются тарифные квоты и правила обеих платформ.
- Это персональная реализация, без публичной регистрации других Spotify-пользователей.
