# Участие в разработке

Wither Spotify Widget развивается как небольшой open-source проект.

1. Для исправлений и новых функций создавай ветку от `main`.
2. Делай изменения небольшими и понятными, не добавляй секреты Spotify.
3. Запусти `npm test` и `npm run check` (Node.js 22+).
4. В PR опиши проблему, изменения и как проверить их в OBS.
5. Для изменения поведения токенов и Spotify API обязательно нужны тесты с подменёнными HTTP-ответами.
6. Не добавляй на сайт сторонние скрипты с доступом к `localStorage`. Обращайся с ним как с хранилищем секретов.

У проекта лицензия GPLv3: отправляемый код должен быть совместим с ней.
