# Участие в разработке

Wither Spotify Widget — персональный открытый проект, сопровождаемый WitherOffic.

Сейчас рабочая ветка только **main**. Новые изменения публикуются отдельными небольшими коммитами непосредственно в main после проверки.

1. Не добавляй в репозиторий Spotify refresh/access tokens, Cloudflare Secrets, pairing и owner keys.
2. При изменениях выполняй `npm test` и `npm run check` (Node.js 22+).
3. Проверяй Actions после каждого обновления. Учти, что автоматические тесты не заменяют работу с живым Spotify и OBS.
4. Правки OAuth и Worker должны сопровождаться тестами обработки ошибок и безопасности.
5. Обновляй README и CHANGELOG при изменении пользовательского поведения.
6. Сохраняй авторские уведомления и условия GPLv3.

Ссылка на оригинальный проект указана в конце README; это самостоятельная модификация, не официальный продукт Spotify или Nutty.
