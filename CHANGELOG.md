# История изменений

## 17 ноября 2026 — единая настройка и ссылка OBS

- Главная страница теперь служит панелью подключения Spotify.
- Добавлена серверная часть Cloudflare Worker + D1 с шифрованием Spotify-токенов.
- Добавлена выдача персональной ссылки просмотра для OBS без JSON и входа в Spotify внутри OBS.
- Добавлены перевыпуск и отзыв ссылок, настройки виджета, деморежим и проверка здоровья Worker.
- Сохранён временный `legacy.html` для старого подключения на период переноса.
- Добавлены тесты серверной логики.

## 17 ноября 2026 — улучшения исходного оверлея

- Переход на Spotify OAuth PKCE без Client Secret в браузере.
- Выделены модули обработки обложек, анимации и авторизации.
- Исправлены ошибки вызова браузерного fetch, таймер и отображение отсутствующих обложек.
- Добавлены тесты, CI и документация по безопасности.
