Wither Spotify Widget

Твой Spotify в OBS

Подключи Spotify один раз, получи готовую ссылку и вставь её в источник «Браузер». Никаких JSON, дополнительных программ или входа в Spotify внутри OBS.

1. Подключить сервис

Для безопасной выдачи ссылок используется твой Cloudflare Worker. Он хранит Spotify-токены на сервере; OBS получает только ключ для чтения музыки.

Где взять Worker и ключ?

Серверная часть находится в папке worker/ репозитория. Для первого запуска нужно один раз развернуть её в Cloudflare, создать базу D1 и добавить два секретных значения. Подробные шаги — в инструкции по настройке Worker.

2. Готовая ссылка для OBS

Spotify подключён. Скопируй эту ссылку в OBS → «Источники» → «Браузер». Авторизация в OBS больше не нужна.

Ссылка содержит отдельный ключ только для чтения текущей музыки. Не публикуй её без необходимости: владелец ссылки сможет видеть воспроизводимые треки, но не получит доступ к управлению Spotify.

Проверить оформление

Демонстрация показывает переключение тестовых композиций без входа в Spotify и без Cloudflare Worker.

Wither Spotify Widget — открытый проект под лицензией GPLv3. Данные о музыке предоставляются Spotify. Первоначальный интерфейс основан на Spotify Widget от Nutty.
