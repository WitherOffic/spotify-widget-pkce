# Wither Spotify Widget

Лёгкий веб-оверлей текущей музыки Spotify для **OBS Studio**. Показывает название, исполнителя, обложку (если она доступна), время и прогресс. При переключении трека текст перелистывается с плавной анимацией.

**Не требует локального сервера, SMTC или отдельного фонового приложения.** Исходник OBS «Браузер» получает данные напрямую из Spotify Web API. Нужен Spotify Developer Client ID и HTTPS-хостинг (например, GitHub Pages).

> **Статус:** персональный open-source проект. Из-за ограничений Spotify Development Mode доступность API зависит от Premium и разрешений приложения. Это не официальный продукт Spotify.

## Быстрый старт

1. Размести содержимое репозитория на GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.
2. В [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) выбери своё приложение с включённым Web API. В **Redirect URIs** добавь точный адрес страницы вида:
   `https://USER.github.io/spotify-widget-pkce/index.html`
3. Открой страницу с параметром `?settings=1`, вставь **Client ID** и нажми **«Подключить Spotify»**. Client Secret не нужен.
4. Разреши приложению читать текущую музыку, затем включи песню.
5. В OBS добавь **Источник → Браузер**, вставь адрес `https://USER.github.io/spotify-widget-pkce/index.html`, ширина `550`, высота `160`.
6. Если браузер OBS не может открыть страницу входа Spotify: в обычном браузере открой `?settings=1`, нажми «Показать подключение для переноса», в OBS через «Взаимодействовать» импортируй JSON. **Не передавай JSON никому** — внутри refresh token.

Пример адреса после публикации: [официальный экземпляр проекта](https://witheroffic.github.io/spotify-widget-pkce/).

### Как проверить без Spotify

Открой `?demo=1` — демонстрационные композиции меняются каждые 6,5 секунд. Токены при этом не нужны.

### Параметры

| Параметр | Что делает |
| --- | --- |
| `?settings=1` | Показывает панель авторизации и диагностики |
| `?demo=1` | Демо без Spotify API |
| `?poll=3000` | Интервал API в миллисекундах (2000–60000, по умолчанию 3000) |
| `?duration=8` | Скрывает карточку через 8 секунд после начала нового трека |
| `?hideAlbumArt` | Скрывает левую обложку |
| `?noAnimation` | Отключает перелистывание текста |

Параметры объединяются через `&`, например `?poll=5000&duration=8`. Более частый опрос повышает риск `429 Too Many Requests` и **не гарантирует** мгновенное отражение паузы.

## Устройство проекта

| Компонент | Ответственность |
| --- | --- |
| `index.html`, `style.css` | HTML и стили прозрачного OBS-оверлея |
| `script.js` | Запуск приложения, состояние воспроизведения, опрос API |
| `player-core.js` | Чистые функции: данные трека, прогресс, форматирование, backoff |
| `src/spotify-auth.js` | OAuth PKCE, обновление токенов и перенос в OBS |
| `src/artwork.js` | Загрузка обложек, кеш, запасные источники и защита от битых URL |
| `src/track-animation.js` | Анимация смены названия и исполнителя |
| `tests/*.test.mjs` | Автотесты без обращения к настоящему Spotify |
| `.github/workflows/test.yml` | Автоматическая проверка при push и pull request |

Никакой сборки и зависимостей для работы в браузере нет. Для локальной проверки нужен Node.js 22+:

```bash
npm test
npm run check
```

## Безопасность и ограничения

- OAuth используется в режиме **Authorization Code + PKCE**; Client Secret нигде не нужен.
- Долгоживущий refresh token сохраняется в `localStorage` **только текущего браузера**. Это не шифрование. Не публикуй JSON переноса, содержимое хранилища, access token и заголовок `Authorization`.
- Chrome и браузер OBS используют разные хранилища. У двух одновременно запущенных копий могут независимо обновляться токены и дублироваться обращения к API.
- Изображения, полученные от Spotify, могут отсутствовать или блокироваться; тогда используется нейтральный фон.
- При паузе Spotify не отправляет браузеру мгновенное событие: реакция зависит от следующего опроса и задержки API.
- Development Mode ограничен условиями Spotify (Premium у владельца, лимит пользователей). Ошибку `403` из-за ограничений Spotify нельзя исправить JS-кодом.
- Этот виджет отображает метаданные. Право показывать название/обложку не равно праву транслировать саму музыку на Twitch.
- Соблюдай [Spotify Developer Policy](https://developer.spotify.com/policy) при публичном использовании, в особенности правила для обложек и атрибуции.
