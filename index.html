ПОДКЛЮЧЕНИЕ

Подключить Spotify

Один раз

Используется твой Cloudflare Worker. Он хранит Spotify-токены на сервере, а OBS получает только ключ просмотра.

Тебя пригласили в Wither Spotify Widget!

Проверь, что владелец добавил твой Spotify-аккаунт в список пользователей приложения. Затем нажми «Подключить Spotify». Никакого Cloudflare и секретов тебе настраивать не нужно.

Не подключено? Как получить Worker

Серверная часть создаётся один раз владельцем. Пошаговая инструкция — в репозитории проекта.

ДЛЯ ВЛАДЕЛЬЦА

Пригласить друга

Одноразовая ссылка

Создай приглашение, которое действует 48 часов. Друг подключит свой Spotify и получит отдельный OBS-оверлей. Главный ключ ему не нужен.

Перед приглашением добавь Spotify-аккаунт друга в User Management своего приложения. В Development Mode число разрешённых пользователей ограничено Spotify.

Управление доступом

Старая ссылка перестанет работать после перевыпуска. Отключение удалит подключение с сервера.
